# Archivo histórico (`docs/legacy/`)

Esta carpeta conserva documentos anteriores a la consolidación Agent-First de noviembre de 2026 **solo como referencia histórica**.

> [!CAUTION] Regla de precedencia
> Ningún documento bajo `docs/legacy/` es fuente de verdad para nuevas tareas. Si contradice al código, a `contracts/openapi.yaml` o a la documentación canónica actual, prevalece la documentación vigente.
