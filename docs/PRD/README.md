# Deprecated PRD Location

> ⚠️ This folder is archived and is not a source of truth.

The canonical Product Requirement Documents live in:

```
/PRD
```

## Agent instruction

Do not read, modify, or create product decisions inside `docs/PRD/`.

Use:

- `/PRD` for product vision, features, roadmap, status, and architecture decisions.
- `/docs/strategy` for strategic context and product direction.
- `/docs` for operational documentation, runbooks, and supporting material.

This directory is preserved temporarily only to avoid breaking old links and references.
