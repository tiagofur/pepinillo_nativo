# Monetization Specification

## Purpose
Define the feature tiers and limitations for Pepinillo+ and Everywhere/AI+.

## Requirements

### Requirement: Tier Parity
The feature tiers MUST offer the same core value across platforms, with platform-specific enhancements clearly labeled.

#### Scenario: Lifetime purchase (Pepinillo+)
- GIVEN a user with Pepinillo+ (Lifetime)
- THEN they MUST have access to all local premium features (Sounds, Themes, Unlimited local tasks)
- AND they MUST have access to platform-specific extras (Watch companion on iOS/Wear OS on Android)

### Requirement: Everywhere/AI+ Subscription
The subscription tier MUST provide cross-platform benefits including Cloud Sync and AI-powered insights.

#### Scenario: AI Reports
- GIVEN a user with Everywhere/AI+
- THEN the system SHOULD provide focus reports (Apple Intelligence on iOS, AI Focus Reports on Android)
