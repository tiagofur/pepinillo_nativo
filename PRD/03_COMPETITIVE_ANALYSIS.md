# Análisis Competitivo Unificado — Pepinillo

**Versión:** 1.0
**Fecha:** 2026-03-20
**Alcance:** iOS + Android + watchOS + Wear OS

---

## 1. Reposicionamiento de Mercado

Pepinillo deja de competir como "app de Pomodoro" (tier de $3.99, commoditizado) para posicionarse como **Deep Work companion** (tier de $25-50/año), donde los márgenes son mayores, los usuarios más leales, y el set competitivo sorprendentemente delgado.

### Set competitivo anterior (Pomodoro):
Forest, Focus Keeper, Be Focused, Flora, Focus To-Do — **saturado, techo de precio bajo, commoditizado.**

### Nuevo set competitivo (Deep Work):
Structured, Session, Things 3 (parcial), Centered, Endel, TickTick, Focus To-Do — **menos saturado, mayor disposición a pagar, espacio para diferenciación.**

### El hueco del mercado

**Ninguna app ofrece todo esto junto:**

1. Múltiples técnicas de enfoque (Pomodoro + Flowtime + Time-Block + Free)
2. Gestión de tareas integrada con vinculación a sesiones de enfoque
3. Integración completa con el ecosistema (Apple: Watch, Dynamic Island, Siri, Focus Modes | Android: Wear OS, Glance, Quick Settings, Assistant, Health Connect)
4. Analytics que comparan efectividad entre técnicas
5. Localización y pricing LATAM-first

Cada competidor cubre 1-3 de estos puntos. Pepinillo cubre los 5.

## 7. Ventajas Competitivas por Plataforma

### 7.1 iOS + watchOS

| Ventaja | Detalle |
|---------|---------|
| **Ecosistema Apple completo** | Watch, Dynamic Island, Live Activities, Siri, Shortcuts, Control Center, Focus Modes — todo integrado |
| **CloudKit sync** | Sincronización automática entre dispositivos Apple sin costo de backend |
| **Liquid Glass (iOS 26)** | Adopción temprana del nuevo lenguaje de diseño de Apple — ventaja de first-mover |
| **Calidad "Apple-native"** | SwiftUI puro, se siente como app de Apple. Benchmark: Things 3, Fantastical |
| **watchOS independiente** | App de reloj completa con timers, tareas rápidas, y complicaciones |

**Apps que validan el pricing premium en iOS:**
- Fantastical ($39.99/yr) — prueba que usuarios Apple pagan premium por apps nativas hermosas
- Craft ($44.99/yr) — misma lección: pricing premium funciona cuando la experiencia Apple-native es best-in-class

### 7.2 Android + Wear OS

| Ventaja | Detalle |
|---------|---------|
| **Material You first** | La mayoría de apps de focus en Android tienen diseño genérico o son ports de iOS. Pepinillo será Material You nativo con dynamic color, predictive back, edge-to-edge |
| **LATAM-first pricing** | Ningún competidor tiene pricing regional agresivo para LATAM. $19.99/yr vs $35-50/yr de competidores |
| **Ecosistema Android completo** | Wear OS + Glance Widgets + Quick Settings + Google Assistant + Health Connect = ningún competidor tiene todo |
| **Backend sync** | Go backend habilita: sync cross-platform (futuro web), analytics server-side, push notifications vía FCM, features colaborativos futuros |
| **Open lane de deep work** | El segmento "Deep Work premium" en Android está **vacío**. Ningún competidor ocupa este espacio |

### 7.3 Ventaja cross-platform única

Pepinillo es la **única app de deep work que cubre los 4 dispositivos** (iPhone, Apple Watch, Android phone, Wear OS) con experiencias nativas en cada uno. Ningún competidor lo hace:

## 8. Riesgos por Plataforma

### 8.1 Riesgos iOS

| Riesgo | Severidad | Mitigación |
|--------|-----------|------------|
| **Scope creep** | 🔴 Alta | Priorización estricta P0/P1/P2. Ship MVP primero |
| **Rechazo de Apple (App Review)** | 🟡 Media | Seguir Human Interface Guidelines al pie de la letra. No features borderline |
| **CloudKit sync issues** | 🟡 Media | Diseño offline-first. Sync es enhancement, no dependency |
| **Desarrollador solo** | 🔴 Alta | Scope realista. Usar SDD para planificar. No sobre-prometer |
| **Structured como competidor** | 🟡 Media | Diferenciarnos con 4 modos + tasks. No competir en diseño 1:1, competir en flexibilidad |

### 8.2 Riesgos Android

| Riesgo | Severidad | Mitigación |
|--------|-----------|------------|
| **Battery optimization de OEMs** | 🔴 Alta | Xiaomi, Samsung, Huawei matan background services. Guiar al usuario a whitelistear la app. Foreground service robusto |
| **Fragmentación** | 🟡 Media | Glance solo funciona bien en API 26+. Algunos launchers no soportan resize. Testear en Samsung Galaxy como referencia |
| **Wear OS baja adopción** | 🟡 Media | Wear OS es ~15% del mercado de smartwatches. ROI menor que watchOS. Mantener scope de Wear OS lean |
| **Play Store discovery** | 🟡 Media | Más competencia y peor discoverability que App Store. ASO (App Store Optimization) es crítico |
| **Play Billing complejidad** | 🟡 Media | Play Billing 7 + verificación server-side. Más complejo que StoreKit 2 |
| **Pricing pressure** | 🟡 Media | Usuarios Android esperan más gratis. Paywall menos agresivo que iOS. Free tier generoso |

### 8.3 Riesgos cross-platform

| Riesgo | Severidad | Mitigación |
|--------|-----------|------------|
| **Paridad de features** | 🔴 Alta | Mantener ambas plataformas sincronizadas es difícil como desarrollador solo. Definir "parity contract" claro |
| **Sync cross-platform (futuro)** | 🟡 Media | CloudKit (iOS) vs Backend Go (Android) dificulta sync entre plataformas. Resolver en fase posterior |
| **Recursos divididos** | 🔴 Alta | Dos codebases nativos = doble trabajo. Mitigar con SDD y planificación estricta |

## 9. Conclusiones Estratégicas

1. **Ningún competidor ofrece 4 modos de focus + tasks + ecosistema completo en AMBAS plataformas.** Esta es una oportunidad genuinamente abierta.
2. **Structured es la amenaza #1 en iOS** — tienen la relación editorial con Apple y calidad de diseño. Pero solo hacen time-blocking.
3. **Focus To-Do es la amenaza #1 en Android** — overlap directo en Pomodoro + tasks. Pero UI anticuada y solo Pomodoro.
4. **El price point de $30-40/yr está validado** por Structured, Fantastical, Craft (iOS) y TickTick (Android).
5. **"Focus your way" / "Trabaja profundo. A tu manera."** es un mensaje poderoso — nos posiciona como la opción flexible vs. competidores de técnica única.
6. **LATAM sigue siendo un mercado sin atender** — ninguna app de focus premium tiene estrategia LATAM.
7. **Usuarios de Things 3 + Forest (iOS) y TickTick + Focus To-Do (Android) son nuestro mejor target de adquisición** — ya pagan por tasks Y focus por separado. Pepinillo reemplaza ambos.
8. **La cobertura de 4 dispositivos (iPhone, Watch, Android, Wear OS) es un diferenciador único** que ningún competidor puede igualar actualmente.
