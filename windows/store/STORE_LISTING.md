## Short description (EN) — max ~256 chars

Calm focus timer and task OS for deep work. Pomodoro, Flowtime, tasks, analytics, soundscapes — with Windows tray mini-timer and hotkeys. Free tier offline; Pepinillo+ unlocks more.

## Long description (EN)

**Pepinillo** is a calm, native **Deep Work OS** for Windows — built to help you start sessions, finish them, and see your progress without noise.

### Focus modes
- **Pomodoro** and **Stopwatch** for structured work
- **Flowtime** and **Time Block** when you need flexible deep work
- Session journaling and task linking so work stays intentional

### Tasks & analytics
- Local-first tasks with lists, priorities, and energy levels
- Dashboard analytics for focus history and mode breakdown
- Offline-first SQLite storage — free tier works without an account

### Windows-native power
- **System tray** status and controls
- **Compact Overlay** mini-timer (always on top)
- **Global hotkeys** to start/pause without breaking flow
- Best-effort **Focus Assist** integration when the OS allows

### Soundscapes & themes
- Ambient soundscapes during sessions (assets may expand over time)
- Light / dark / system theme support

### Account & sync (optional)
- Sign in to sync with the Pepinillo backend when you want cross-device continuity
- Free offline use always available

### Pepinillo+ & Everywhere
- Unlock advanced productivity features with **Pepinillo+** (Windows Store durable add-on)
- Cross-platform **Everywhere** subscriptions when available (see in-app paywall)
